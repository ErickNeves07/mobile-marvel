# 023 — Comic Vine — Design

Use Python stdlib urllib with injectable transport. Search `/search/` resource=character with bounded query, limit/offset and minimal fields; validate returned publisher when available, then resolve detail before accepting Marvel. Detail uses the Comic Vine resource identifier `/character/4005-{id}/`; the numeric `id` alone returned `status_code=102` in a live check on 2026-10-04. The Wolverine detail response identified publisher `{'id': 31, 'name': 'Marvel'}`; accept that exact ID or normalized `Marvel`/`Marvel Comics` name. `4010` is the publisher resource type prefix. Validate upstream status/payload and HTTPS Comic Vine URLs. Process-local TTL cache and lock-protected global one-request/second throttle plus per-resource hourly budget. Return attribution and editorial link, never cache binary assets. Multi-instance deployment needs shared cache/limiter before scaling.
